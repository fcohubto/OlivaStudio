01
Textos sistémicamente por debajo de 14px
css/styles.css · --text-xs (11.5px) · 10+ componentes afectados
Accesibilidad AA Esfuerzo bajo

CLAUDE.md define 14px como mínimo absoluto en pantalla para cualquier texto legible. El sistema de tokens define --text-xs: 0.72rem (~11.5px) y --text-2xs: 0.68rem (~11px). Ambos se usan en elementos que el usuario necesita leer.

Componentes afectados 
--text-xs (11.5px):  .section-label, .narrative-label, .section-eyebrow,
                     .framework-card-tag, .servicio-tag, .form-hint,
                     .equipo-titulo, .contact-info-label, .framework-oliva-sub

--text-2xs (11px):  .footer-col-title  ← peor infractor
Fix recomendado

Redefinir --text-xs a 0.875rem (14px) y eliminar --text-2xs. Todos estos elementos son etiquetas uppercase con letter-spacing amplio — a 14px siguen siendo compactos visualmente y pasan el mínimo de accesibilidad. Alternativa: reemplazar todos los usos de --text-xs por --text-sm (que ya vale 0.875rem en este sistema).

02
Automatización IA: servicio en el form, invisible en Capacidades
index.html · #servicios · form#contacto-form
Conversión Esfuerzo medio

El formulario ofrece "Automatización IA" como opción de contacto. La sección Capacidades muestra 4 narrative blocks: UI/UX, Desarrollo Web, Auditoría UX, Estrategia Digital. Automatización IA — el servicio de mayor demanda y búsqueda activa hoy — no tiene presencia narrativa en el sitio. Un prospecto que llega por ese interés no encuentra ninguna propuesta de valor antes de contactar.

Disconnect actual 
Checkboxes del form:
  ✓ Diseño y Desarrollo Web
  ✓ Sistema / App Web
  ✓ UX / UI
  ✓ Sistema de Gestión
  ✓ Automatización IA        ← sin sección narrativa
  ✓ Auditoría Web
  ✓ Product Discovery
  ✓ No sé aún — necesito orientación
Opciones de fix

Opción A: Agregar un 5.° narrative block "Automatización IA Powered" entre Auditoría UX y Estrategia Digital. Texto corto, SVG ilustrativo reutilizando el estilo existente.

Opción B (mínimo): En el cuerpo del Hero o en la descripción de Desarrollo Web, mencionar explícitamente las automatizaciones IA como capacidad integrada del framework OLIVA.

03
FAQ ausente del footer — inconsistencia de navegación
index.html · .footer-col "Navegación"
Coherencia Trivial

Nav desktop: Capacidades / El Framework / Estructura / FAQ / Contacto. Footer nav: Capacidades / El Framework / Estructura / Contacto. FAQ no aparece. El usuario que llega al footer buscando más información no tiene acceso directo al FAQ desde ahí.

Fix — una línea 
<ul role="list">
  <li><a href="#servicios">Capacidades</a></li>
  <li><a href="#framework">El Framework</a></li>
  <li><a href="#estructura">Estructura</a></li>
  <li><a href="#faq">FAQ</a></li>
  <li><a href="#contacto">Contacto</a></li>
</ul>

05
H1 hero restringido a 3rem — desaprovecha pantallas grandes
css/styles.css · #hero h1 · clamp(1.9rem, 4vw, 3rem)
Impacto visual Trivial

El CSS base define h1 { font-size: clamp(2.75rem, 7vw, 5rem) }. La override del hero lo limita a clamp(1.9rem, 4vw, 3rem) — topa en 48px en desktop. Con la grilla de dos columnas hay espacio para un H1 más impactante.

Fix sugerido 
#hero h1 {
  font-size: clamp(1.9rem, 4vw, 3rem);      ← actual (máx 48px)
  font-size: clamp(2.1rem, 4.5vw, 3.75rem); ← sugerido (máx ~60px)
}
06
Anelisse aparece solo con nombre de pila
index.html · #estructura · .persona-name
Credibilidad Trivial

Francisco aparece como "Francisco Orellana" con nombre y apellido. Anelisse aparece solo como "Anelisse". En una sección que vende rigor profesional y equipo de confianza, la asimetría de identificación resta credibilidad.

Fix

Agregar el apellido de Anelisse, o adoptar formato consistente: solo nombre de pila para ambos. Cualquier opción es válida — lo que no es válido es la asimetría.

07
Sin sitemap.xml ni robots.txt
raíz del dominio · SEO técnico
SEO Esfuerzo bajo

No hay sitemap.xml ni robots.txt en el servidor. Para un sitio de una sola página el impacto es moderado — Google lo indexa igual — pero el sitemap acelera el crawling y el robots.txt evita comportamientos inesperados de bots.

sitemap.xml mínimo 
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://olivacraft.com/</loc>
    <changefreq>monthly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>
🔧
Mantenibilidad
No afectan al usuario. Deuda técnica para la próxima refactorización.

09
Tokens --c-od-* duplican la escala --c-ink-*
css/styles.css · :root · 9 tokens redundantes
Tokens Esfuerzo bajo

El :root mantiene dos familias paralelas: --c-ink-* (sistema activo) y --c-od-* (herencia). Los tokens --c-od-* solo se usan en footer y modal — ambos pueden reescribirse con los equivalentes --c-ink-*.

Tokens redundantes 
--c-od-text   → --c-ink        (0.85 ≈ 0.90)
--c-od-body   → --c-ink-soft   (0.45 ≈ 0.60)
--c-od-muted  → --c-ink-muted  (0.30 ≈ 0.38)
--c-od-dim    → --c-ink-faint  (0.25 ≈ 0.22)
... + 5 tokens más (faint, border, line, bg, bg-mid)
10
Meta description 8 caracteres bajo el mínimo recomendado
index.html · <head> · meta name="description"
SEO menor Trivial

La meta description actual tiene 142 caracteres. El rango recomendado es 150–160 para maximizar el snippet en resultados de búsqueda. Son 8 caracteres de diferencia.

Actual (142 chars) 
"Olivacraft es una consultora tecnológica boutique. Diseño, desarrollo
web y automatización IA estructurados bajo OLIVA, nuestro framework IA."
Sugerido (~155 chars)

"Olivacraft es una consultora tecnológica boutique. Diseño, desarrollo web y automatización IA — estructurados bajo OLIVA, nuestro framework propietario. Entregamos más rápido con el mismo rigor."

OK · 7
✓
Formulario con checkboxes múltiples Mejor que un dropdown — los clientes suelen necesitar más de un servicio. Reduce fricción y da contexto pre-calificado.
✓
FAQ con accordion CSS El patrón grid-template-rows es moderno, sin JS extra. Reduce sobrecarga visual sin ocultar información relevante.
✓
Focus visible + prefers-reduced-motion Ambos implementados correctamente. Diferencia mouse de teclado. Respeta accesibilidad vestibular.
✓
aria-hidden en SVGs ilustrativos Todos los SVGs decorativos tienen aria-hidden="true". Labels visibles en inputs. fieldset + legend en checkboxes.
✓
WhatsApp flotante sin glow verde La sombra neutra evita el patrón visual IA-genérico. CTA de conversión directa sin agresividad visual.
✓
Framework section: sticky + steps Layout dos columnas con OLIVA card sticky funciona narrativamente. Muestra el sistema, no solo lo describe.
✓
Nav breakpoint en 1024px Decisión correcta — 4 ítems + logo + CTA no caben en 768px. El hamburger en tablet evita overflow.
